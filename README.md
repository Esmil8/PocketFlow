# PocketFlow - Personal Finance Manager

**PocketFlow** is a full-stack personal finance management application designed to help individuals track, analyze, and optimize their daily spending habits. With an intuitive interface and powerful analytics, PocketFlow transforms raw expense data into actionable financial insights.

##  Key Features

- **Expense Tracking** — Add, edit, and delete expenses with categories, amounts, and dates.
- **Advanced Analytics** — Visual breakdown of spending by category and month with interactive charts.
- **Smart Budgeting** — Set monthly spending limits per category and receive real-time alerts when approaching or exceeding them.
- **Expense Filtering** — Search and filter transactions by category or date range.
- **Responsive Design** — Accessible on desktop, tablet, and mobile devices.

## Technology Stack

| Layer | Technology |
| :--- | :--- |
| **Backend** | Node.js, Express.js, MongoDB, Mongoose ODM |
| **Frontend** | React |
| **Validation** | Express-validator |
| **Environment** | Dotenv for configuration management |
| **Development** | Nodemon for hot reloading |
